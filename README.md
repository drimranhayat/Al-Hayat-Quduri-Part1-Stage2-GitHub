# الحیات مرکز علوم اسلامیہ — شرح القدوری

ڈاکٹر عمران حیات کی تدریسی پیشکش۔ جلد اوّل، کتاب الطہارت کی پہلی تدریسی کھیپ۔

## شامل مواد

مطبوعہ صفحات ۴۷–۵۶ سے چھ مربوط اسباق: طہارت، فرائض وضو، آغاز میں ہاتھ دھونا، تسمیہ و مسواک و کلی و استنشاق، مسح و خلال و تکرار غسل، اور مستحبات وضو۔ صفحہ ۵۶ پر شروع ہونے والی نواقض وضو کی بحث اگلی کھیپ کے لیے ہے۔ یہ پوری جلد یا مکمل کتاب الطہارت نہیں۔

ہر سبق کے نو حصے ہیں: سبق و تشریح، احکام و طریقہ، الفاظ معانی، تراکیب، عربی قواعد، دلائل و اقوال، عملی مشق، سوال جواب، MCQs۔ اس نسخے میں ۵۰ لفظی اندراجات، ۴۸ مختصر سوال جواب، ۳۶ MCQs اور ۱۲ عملی مشقیں ہیں۔ ہر سبق میں ایک اضافی خودکار لفظ مکمل کرنے کی مشق بھی ہے۔

رنگ ہر سبق کے لیے الگ ہیں۔ اردو اور عربی کے مقامی فونٹ، دن و رات تھیم، محفوظ اسباق، نوٹس، پیش رفت اور اس کی نقل محفوظ/بحال کرنے کی سہولت شامل ہے۔ کوئی اکاؤنٹ یا سرور ڈیٹابیس نہیں۔ معلومات اسی براؤزر میں رہتی ہیں۔

## چلانے کا طریقہ

فولڈر میں یہ کمانڈ چلائیں:

```sh
python3 -m http.server 8000
```

پھر `http://localhost:8000` کھولیں۔ کوئی build یا npm درکار نہیں۔

## GitHub Pages

فولڈر کے اندر کی تمام فائلیں، `.github` سمیت، repository کی root میں رکھیں۔ `main` برانچ استعمال کریں۔ Settings → Pages → Source میں GitHub Actions منتخب کریں۔ شامل workflow push پر یا دستی طور پر چلایا جا سکتا ہے۔

## اگلی کھیپ

موجودہ اسباق کو برقرار رکھ کر `data.js` میں اگلے مستقل IDs والے اسباق شامل کریں۔ متن کی نقل OCR سے براہ راست شائع نہ کریں؛ اصل صفحے سے تصحیح کریں۔ سوالات، تراکیب اور قواعد اسی نئے متن کے مطابق ہوں۔ ہوم پیج، کوئز کی کل تعداد، کوریج اور اس دستاویز کی گنتی بھی نئی کھیپ کے مطابق اپ ڈیٹ کریں۔ موجودہ localStorage کلید برقرار رکھنے سے طالب علم کے نوٹس اور پیش رفت محفوظ رہیں گے۔

```sh
node scripts/validate.cjs
```

موجودہ validator اسی پہلی کھیپ کی تعداد اور صفحوں کی حد جانچتا ہے؛ کھیپ بڑھانے کے ساتھ اس کی توقعات بھی درست کریں۔
